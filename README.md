# 이야기 만들기 카드

6세 유치원생이 그림과 짧은 단어를 보고 직접 이야기를 만들고 발표할 수 있도록 돕는 수업용 웹앱입니다. 웹앱은 이야기의 소재만 제공하며 완성 문장, 예시 이야기, 정답이나 점수를 만들지 않습니다.

## 실행 방법

별도 설치나 빌드 과정이 필요하지 않습니다.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. ES 모듈을 사용하므로 `index.html`을 파일로 직접 여는 대신 로컬 서버를 이용해 주세요.

## 카드 데이터 추가 방법

`cardData.js`에서 원하는 분류의 배열에 항목을 추가합니다. 모든 항목은 같은 구조를 사용합니다.

```js
createCard("fox", "여우", "🦊", "characters")
```

- 첫 번째 값: 다른 카드와 겹치지 않는 영문 ID
- 두 번째 값: 화면에 표시할 짧은 단어 또는 표현
- 세 번째 값: 이미지가 없을 때 표시할 이모지
- 네 번째 값: 이미지 폴더명 (`characters`, `places`, `events`, `emotions`)

## 이미지 교체 방법

각 카드의 이미지 경로는 자동으로 `assets/분류/ID.png`가 됩니다. 예를 들어 토끼 그림은 다음 위치에 넣습니다.

```text
assets/characters/rabbit.png
```

기본 카드 53종의 PNG 이미지가 이미 포함되어 있습니다. 같은 파일명으로 교체하면 코드 수정 없이 새 그림이 표시되고, 파일이 없거나 불러오지 못하면 이모지가 표시됩니다. 투명 배경의 정사각형 이미지를 권장합니다. WebP를 사용하려면 `cardData.js`의 `createCard` 함수에서 확장자 `.png`를 `.webp`로 바꿔 주세요.

## GitHub Pages 배포 방법

1. 이 폴더를 GitHub 저장소의 기본 브랜치에 올립니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment**의 Source를 **Deploy from a branch**로 선택합니다.
4. 기본 브랜치와 `/ (root)` 폴더를 선택한 뒤 저장합니다.
5. 표시되는 GitHub Pages 주소에서 배포된 웹앱을 확인합니다.

모든 링크가 상대 경로로 작성되어 있어 별도의 경로 설정 없이 프로젝트 페이지에서도 동작합니다.
